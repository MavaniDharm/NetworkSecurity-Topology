# 🔐 Network Security Topology Projects

## 📌 About This Repository

Welcome to my **Network Security Topology** repository!

This repository contains practical networking and network security labs created using **Cisco Packet Tracer**. These projects help me understand network security concepts, router and switch configurations, access control, authentication, and Network Address Translation (NAT).

I am continuously learning and improving my networking and cybersecurity skills through hands-on practice.

## 🎯 Objectives

- Understand networking and network security fundamentals.
- Practice router and switch configurations.
- Implement authentication and access control.
- Learn network traffic filtering using ACLs.
- Configure NAT, Dynamic NAT, Static NAT, and PAT.
- Understand DHCP Snooping and Port Security.
- Explore firewall concepts using Cisco ASA.
- Build practical networking skills through lab simulations.

## 🛠️ Tools Used

- Cisco Packet Tracer
- Cisco Routers
- Cisco Catalyst 2960 Switches
- Cisco ASA 5506-X Firewall
- PCs and Servers
- Networking and Security Protocols

## 📂 Projects Included

| No. | Project | Description |
|---|---|---|
| 1 | AAA Authentication | Authentication, Authorization, and Accounting concepts |
| 2 | Telnet | Remote device access using Telnet |
| 3 | DHCP Snooping | Protection against unauthorized DHCP servers |
| 4 | Port Security | Restricting unauthorized devices on switch ports |
| 5 | Standard ACL | Filtering traffic based on source IP addresses |
| 6 | Extended ACL | Filtering traffic based on source, destination, and protocols |
| 7 | Static NAT | Mapping private IP addresses to public IP addresses |
| 8 | Dynamic NAT | Translating private IP addresses using an address pool |
| 9 | PAT | Translating multiple private IP addresses using port numbers |
| 10 | Firewall | Network segmentation using a Cisco ASA 5506-X firewall |
