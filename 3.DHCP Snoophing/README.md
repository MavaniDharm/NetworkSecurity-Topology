# 🔐 AAA Authentication – Cisco Packet Tracer

## 📌 Project Overview
This project demonstrates a basic network topology with a Cisco router, a switch, three PCs, and a server. It focuses on router access security using username and password authentication.

The project helps understand basic Cisco IOS security commands and network connectivity.

## 🎯 Objectives
- Understand AAA and router access security.
- Configure local username and password authentication.
- Configure an enable password for privileged EXEC mode.
- Understand IP addressing and default gateways.
- Test network connectivity using ping.
- Learn basic Cisco IOS configuration.

## 🖥️ Network Topology
The network consists of:

- **1 Router:** Router1
- **1 Switch:** Cisco 2960-24TT Switch0
- **3 PCs:** PC1, PC2, PC3
- **1 Server:** Server0
