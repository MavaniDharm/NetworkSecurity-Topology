# 🔐 AAA (Authentication, Authorization, Accounting) – Cisco Packet Tracer

## 📌 Project Overview
This project demonstrates a basic network topology using Cisco Packet Tracer. It includes a router, a switch, two PCs, and a server connected within the same network.

The topology is designed as a foundation for understanding AAA (Authentication, Authorization, and Accounting) in network security.

## 🎯 Objectives
- Understand AAA concepts in network security.
- Configure basic network connectivity.
- Learn how routers, switches, PCs, and servers communicate.
- Understand the role of a server in network authentication.
- Practice network security concepts using Cisco Packet Tracer.

## 🖥️ Network Topology
The network consists of the following devices:

- **1 Router:** Router1
- **1 Switch:** Cisco 2960-24TT Switch0
- **2 PCs:** PC0 and PC1
- **1 Server:** Server0

## 🌐 IP Addressing Table

| Device | IP Address |
|---|---|
| Router1 | 192.168.1.254 |
| PC0 | 192.168.1.2 |
| PC1 | 192.168.1.1 |
| Server0 | 192.168.1.3 |

**Network Address:** 192.168.1.0/24  
**Subnet Mask:** 255.255.255.0  
**Default Gateway:** 192.168.1.254

## 🧪 Testing
The following tests can be performed:

1. Verify the IP configuration of each device.
2. Ping PC0 from PC1.
3. Ping the server from both PCs.
4. Verify connectivity between the router and end devices.
5. If AAA is configured, test the authentication process using the configured credentials.

## 🔒 What Is AAA?

- **Authentication:** Verifies the identity of a user.
- **Authorization:** Determines what an authenticated user is allowed to do.
- **Accounting:** Records user activities and resource usage.

## 📚 Learning Outcomes

- Learning the fundamentals of AAA in network security.
- Understanding the role of authentication servers in network environments.

## 📝 Note
This topology illustrates the basic network infrastructure for an AAA lab. Actual AAA functionality requires additional configuration, such as local user authentication or a supported AAA server (for example, RADIUS or TACACS+).
